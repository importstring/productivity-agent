# Productivity Agent

A multi-agent system designed to enhance personal productivity through automated monitoring, analysis, and assistance.

## Features

- Posture monitoring and recording
- Nightly analysis of productivity data
- Verbal and written question answering
- Data insertion and management capabilities

## Requirements

- Python 3.8+
- Required packages (see `requirements.txt`)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/productivity-agent.git
cd productivity-agent
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the main application:

```bash
python main.py
```

The system provides the following options:

1. Record posture (5-minute sessions)
2. Run nightly analysis
3. Answer verbal questions
4. Answer written questions
5. Insert data

## Configuration

System configuration can be modified in `src/config/system_config.json`.
